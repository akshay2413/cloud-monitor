# Cloud Monitor – Cloud Resource Monitoring Dashboard

## About
Cloud Monitor is a web-based dashboard designed to manage and monitor cloud resource information through a simple interface.

## Features
- User Login
- Dashboard Overview
- Add, Edit, and Delete Resources
- Search and Filter Resources
- View Resource Details
- Refresh Dashboard Data

## Technologies Used
- **Frontend:** React.js, JavaScript, HTML, CSS
- **Backend:** C#, ASP.NET Core Web API
- **Database:** MySQL
- **Tools:** Visual Studio Code, Git, GitHub

## How to Run
1. Download or clone the project.
2. Open the project in Visual Studio Code.
3. Install the required dependencies.
4. Configure and start the backend and database.
5. Start the frontend application.
6. Open the local URL in your browser.

## Purpose
This project demonstrates full-stack web development, dashboard design, API integration, and database connectivity.
